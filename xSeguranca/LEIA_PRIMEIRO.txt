# 🎬 SISTEMA DE VIGILÂNCIA - COMEÇAR AGORA (3 min)

---

## 👇 SIGA EXATAMENTE ISTO

### 1. Abra terminal/CMD nesta pasta

```bash
# Verificar que tem os arquivos:
ls -la start.sh    # macOS/Linux
dir start.bat      # Windows
```

### 2. Rodar 1 comando

**macOS/Linux:**
```bash
chmod +x start.sh
./start.sh
```

**Windows:**
```
Duplo clique em: start.bat
# ou abra CMD aqui e digite: start.bat
```

### 3. Aguarde 30 segundos

Browser abrirá sozinho em: **http://localhost:3000**

### 4. Verificar

```
✅ Mapa aparece
✅ 2 câmeras: 🎥 🎥
✅ Status: "🟢 2/2 câmeras online"
```

**Pronto! Sistema rodando.** 🎉

---

## 🎯 E se não funcionar?

**Problema:** Câmeras aparecem 🔴 (offline)

```bash
# Terminal:
ping 192.168.0.198
ping 192.168.0.199
# Devem responder
```

**Problema:** "Docker not found"

→ Instale: https://www.docker.com/products/docker-desktop

**Problema:** Qualquer outro erro

→ Ler arquivo: **TESTE_PRATICO_2_CAMERAS.md** (troubleshooting)

## 📅 Amanhã (quando chegar as 3 térmicas)

Arquivo: **AMANHA_ADICIONAR_TERMICAS.md**

5. Verificar 5/5 online

**5 minutos, sem parar nada.**
