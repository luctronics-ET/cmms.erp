## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser DOM → rendered roster | Member-supplied strings (nome, especialidade) rendered into the page |
| browser → /api/manutencao/equipe/* | Frontend sends Bearer token + JSON to the backend |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-06 | Tampering (XSS) | roster rendering | high | mitigate | All member-supplied text rendered via el()/textContent — never innerHTML with raw input |
| T-04-07 | Spoofing | equipe API calls | high | mitigate | Every fetch sends `Authorization: Bearer <xcmasm_token>`; backend enforces auth (Wave 1) |
| T-04-08 | Repudiation | capacity display | low | accept | Capacity shown is the backend-computed value (single source of truth); frontend never invents numbers |
</threat_model>
