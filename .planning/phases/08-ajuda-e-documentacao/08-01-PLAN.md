<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /api/docs (multipart upload) | Untrusted file bytes, filename, content-type, and categoria cross here |
| /api/docs/.../download → filesystem | DB-stored relative path is resolved to a real file path |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-01 | Tampering | upload categoria / arquivo_nome → on-disk path | high | mitigate | categoria validated against ALLOWED_CATS frozenset; stored path = data/documentos/<categoria>/<doc_id>_v<versao><ext> built only from server-controlled values; client filename kept solely as arquivo_nome metadata |
| T-08-02 | Information Disclosure | download path resolution | high | mitigate | os.path.normpath on the resolved path + assert it startswith os.path.abspath(_DATA_DOCS); 403 on escape, 404 on missing file |
| T-08-03 | Spoofing | content-type spoofing on upload | medium | mitigate | security decision uses the filename EXTENSION against ALLOWED_EXTS; client content_type stored only as metadata for the download Content-Type |
| T-08-04 | Denial of Service | unbounded upload size | medium | mitigate | read at most MAX_UPLOAD_BYTES+1 (25 MB) then 413 before writing to disk |
| T-08-05 | Elevation of Privilege | visualizador performing writes | high | mitigate | _require_escrita on PUT /ajuda, POST /documentos, POST /versoes → 403 |
| T-08-06 | Tampering | concurrent uploads racing the version number | medium | mitigate | SELECT COALESCE(MAX(versao),0)+1 and INSERT in one aiosqlite connection/commit; UNIQUE(documento_id,versao) is the DB backstop |
| T-08-SC | Tampering | npm/pip/cargo installs | high | accept | No new packages this phase — python-multipart and aiofiles already in requirements.txt (RESEARCH Package Legitimacy Audit: not applicable) |
</threat_model>
