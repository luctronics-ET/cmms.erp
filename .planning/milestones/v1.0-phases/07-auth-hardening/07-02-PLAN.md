<objective>
Remove the hardcoded default password (`1234` / its djb2 form `170842`) from every
write path: the login fallback, POST /api/usuarios, and PUT /api/usuarios. After this
plan an account with no stored hash cannot authenticate (HTTP 401), and creating/editing
a user without a senha leaves the hash empty rather than silently granting the well-known
default credential. This plan implements SEC-02. It depends on plan 07-01 because (a) both
edit the same login handler in backend/main.py (file conflict -> sequential wave) and
(b) removing the default is only safe AFTER the Argon2 verify + lazy-upgrade path and its
no-lockout test from 07-01 exist.

Purpose: a hardcoded default password is a critical auth bypass — anyone can log into any
account that was never given a real password.

Output: backend/main.py with all `_djb2("1234")` defaults removed; tests/test_auth.py
extended with NULL-hash and no-default tests.
</objective>
